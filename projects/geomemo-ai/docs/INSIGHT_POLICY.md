# 주간 인사이트 정책

## 문제의식

GeoMemo의 주간 인사이트는 사용자의 감정 로그를 바탕으로 한 줄 조언을 제공합니다. 하지만 프로젝트 당시에는 실제 사용자 로그가 충분하지 않았기 때문에 결과가 마음에 들지 않거나, 근거보다 문장이 앞서는 느낌이 날 수 있었습니다.

따라서 인사이트 worker는 다음 원칙을 따릅니다.

- 데이터가 적어도 사용자가 받을 수 있는 가벼운 조언은 제공한다.
- 다만 패턴, 장소 영향, 원인처럼 근거가 필요한 말은 최소 데이터 기준을 넘었을 때만 한다.
- OpenAI API 호출 전에 감정 로그를 구조화하고, 근거 수준을 먼저 판단한다.

## 최소 데이터 기준

| 기준 | 처리 방식 |
| --- | --- |
| 감정 로그 0건 | 개인화된 경향을 말하지 않고, 기록을 유도하는 안내만 제공 |
| 감정 로그 1-2건 | `light` 수준. 경향을 단정하지 않고 가벼운 컨디션 조언만 제공 |
| 감정 로그 3-4건 | `limited` 수준. 제한적 경향으로만 표현 가능 |
| 감정 로그 5건 이상 | `normal` 수준. 주간 경향을 조심스럽게 요약 가능 |
| 같은 장소 카테고리 2건 이상 | 장소별 감정 경향을 언급 가능 |

이 기준은 최종 정답이 아니라 초기 안전장치입니다. 실제 사용 로그가 쌓이면 unknown 비율, 클릭/저장 반응, 사용자 피드백을 보고 조정해야 합니다.

## 왜 장소 기준은 2건인가

장소 카테고리 1건만으로 “카페에서 감정이 좋았다/나빴다”고 말하면 우연한 하루를 패턴처럼 해석할 위험이 큽니다. 그래서 장소별 valence는 같은 카테고리 기록이 최소 2건 이상일 때만 계산합니다.

예를 들어 다음처럼 세 장소가 각각 1건씩만 있으면 장소별 인사이트는 만들지 않습니다.

```json
[
  {"label": "기쁨", "category": "공원"},
  {"label": "불안", "category": "사무실"},
  {"label": "놀람", "category": "카페"}
]
```

반대로 `공원` 기록이 2건 이상이면 “공원에서 감정이 좋게 남는 편”처럼 제한적인 장소 경향을 말할 수 있습니다.

## GPT 사용 기준

현재 worker는 근거가 약한 경우 GPT 요약으로 바로 넘기지 않고 `build_light_advice`로 deterministic한 짧은 조언을 만듭니다.

- `can_make_pattern_claim = false`: GPT 호출 없이 가벼운 조언
- `can_make_place_claim = false`: 장소 단정 없이 감정 중심의 조언
- 둘 다 true: 집계 결과를 바탕으로 GPT 요약 가능

이렇게 하면 로그가 적을 때도 응답은 제공하되, LLM이 근거보다 그럴듯한 문장을 앞세우는 문제를 줄일 수 있습니다.

## 포트폴리오 설명 문장

> 주간 인사이트 결과가 실제 로그 부족 상황에서 과하게 단정적으로 보일 수 있다는 문제를 발견했다. 이를 개선하기 위해 로그 개수와 장소 카테고리 반복 여부를 기준으로 근거 수준을 나누고, 데이터가 적을 때는 GPT 요약 대신 가벼운 deterministic 조언만 제공하도록 정책을 분리했다.
