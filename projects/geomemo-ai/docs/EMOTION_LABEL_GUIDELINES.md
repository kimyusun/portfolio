# 감정 라벨 가이드

## 목적

GeoMemo-AI는 사용자의 짧은 메모를 6개 감정 라벨 중 하나로 분류합니다. 실제 감정은 복합적이지만, 현재 모델은 단일 라벨 분류 구조이므로 문장마다 primary label을 하나 정해야 합니다.

이 문서는 사람이 라벨을 검토하거나 보강 데이터를 만들 때 같은 기준을 적용하기 위한 가이드입니다.

## 라벨 목록

| index | label | stage1 | 해석 |
| ---: | --- | --- | --- |
| 0 | 기쁨 | 긍정 | 만족, 즐거움, 뿌듯함, 편안함 |
| 1 | 놀람 | 긍정 | 예상 밖 사건, 당황, 깜짝 놀람 |
| 2 | 분노 | 부정 | 화, 짜증, 불쾌, 억울함 |
| 3 | 불안 | 부정 | 걱정, 긴장, 불확실성, 위험 예측 |
| 4 | 상처 | 부정 | 타인의 말/행동으로 인한 마음의 아픔 |
| 5 | 슬픔 | 부정 | 상실감, 외로움, 허전함, 우울감 |

## Primary Label 판단 기준

### 상처

감정의 직접적인 원인이 타인의 말, 행동, 관계적 거절, 무시, 비교, 배신에 있을 때 사용합니다.

예시:

- 친구가 내 말을 대수롭지 않게 넘겨서 마음이 아팠다.
- 회의에서 내 의견이 무시당한 뒤 계속 작아지는 기분이었다.
- 믿었던 사람이 내 이야기를 가볍게 여긴 것 같아 속상했다.

슬픔이 함께 있더라도 원인이 관계적 상처라면 primary label은 `상처`로 둡니다.

### 슬픔

상실감, 외로움, 허전함, 공허함, 우울감처럼 감정의 중심이 내면의 침잠에 있을 때 사용합니다.

예시:

- 집에 돌아오는 길이 유난히 조용해서 마음이 허전했다.
- 좋아하던 공간이 사라진 걸 보니 마음이 비어버린 것 같았다.
- 괜찮다고 말했지만 하루 종일 마음이 가라앉아 있었다.

누군가와 관련된 사건이 있더라도 문장의 중심이 타인의 가해보다 외로움/상실감이라면 primary label은 `슬픔`으로 둘 수 있습니다.

### 불안

아직 일어나지 않은 일, 불확실성, 걱정, 긴장, 위험 예측이 중심일 때 사용합니다.

예시:

- 내일 결과가 어떻게 나올지 몰라 하루 종일 조마조마했다.
- 답장이 없어서 무슨 일이 생긴 건 아닌지 걱정됐다.
- 처음 맡은 일이라 실수할까 봐 마음이 계속 불안했다.

슬픔이나 상처가 함께 있더라도 핵심이 미래의 불확실성이라면 primary label은 `불안`입니다.

## 복합 감정 처리

현재 모델은 단일 라벨만 예측하지만, 사람이 검토할 때는 secondary label을 남길 수 있습니다.

예:

| text | primary | secondary | 이유 |
| --- | --- | --- | --- |
| 친구가 연락을 피하는 것 같아 마음이 허전했다. | 상처 | 슬픔 | 관계적 거절이 원인이고 슬픔이 동반됨 |
| 결과가 오지 않아 힘이 빠지고 걱정됐다. | 불안 | 슬픔 | 불확실한 결과 대기가 중심이고 침잠이 동반됨 |
| 아무도 나를 찾지 않는 것 같아 외로웠다. | 슬픔 | 상처 | 내면의 외로움이 중심이고 관계적 상처가 동반됨 |

secondary label은 모델 학습 라벨을 바로 바꾸기 위한 값이 아니라, 단일 라벨 모델의 한계와 future multi-label 확장 가능성을 기록하기 위한 값입니다.

## 라벨 변경 원칙

boundary review에서 기존 `true_label`을 바꿀 때는 다음 기준을 따릅니다.

1. 모델이 맞혔다는 이유만으로 라벨을 바꾸지 않습니다.
2. 사람이 읽어도 기존 라벨보다 다른 라벨이 primary emotion에 더 가깝다고 판단될 때만 바꿉니다.
3. 복합 감정이면 `review_label`에는 primary label을, `secondary_label`에는 보조 감정을 적습니다.
4. 지나치게 애매하거나 문장 품질이 낮으면 학습 데이터로 바로 쓰지 않고 별도 검토 대상으로 둡니다.

## 현재 검토 결과 요약

2026-06-01 기준 boundary 후보 54개를 사람이 검토했습니다.

- `review_label`이 채워진 행: 18개
- 실제 라벨 변경: 17개
- `secondary_label`이 있는 행: 15개
- 주요 변경: `상처 -> 슬픔`, `슬픔 -> 불안`, `슬픔 -> 상처`
- 주요 복합 감정: `불안+슬픔`, `슬픔+불안`, `슬픔+상처`, `상처+슬픔`

이 결과는 모델이 무조건 틀렸다는 뜻이 아니라, 기존 단일 라벨 데이터에 복합 감정이 섞여 있었고 라벨 경계 기준을 더 명확히 해야 한다는 근거입니다.

## 포트폴리오 설명 문장

> 감정은 복합적으로 나타나기 때문에 오답 사례를 단순히 모델 오류로만 보지 않았습니다. `상처/슬픔/불안` 경계 사례를 사람이 다시 검토하고, primary label과 secondary label을 분리해 단일 라벨 모델의 한계를 문서화했습니다. 이를 통해 현재 모델은 baseline으로 유지하되, 향후 multi-label 또는 primary-secondary emotion 구조로 확장할 수 있는 근거를 마련했습니다.
